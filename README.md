# Cycle Care

Cycle Care is a private, local-only Android menstrual cycle tracker built with Kotlin and Jetpack Compose.

## Features

- Starts with a 28-day estimate and learns the median of recent completed cycles.
- Shows menstrual, follicular, estimated ovulation, luteal, and premenstrual dates.
- Records bleeding, pain, symptoms, medicine taken, and notes in Room.
- Schedules private period and optional phase notifications with WorkManager.
- Provides adult-focused home-care and safety-gated OTC medicine information.

Predictions are for cycle awareness only. They cannot confirm ovulation and must not be used as contraception. Health guidance is educational and does not replace a clinician or pharmacist.

## Build

Open the project in Android Studio or run:

```shell
./gradlew testDebugUnitTest assembleDebug
```
